## Self-Custody by Default

NET is a standard ERC-20 token on the Polygon network. It can be held and managed using any Polygon-compatible self-custody wallet, such as MetaMask or Trust Wallet, independent of any specific Netlink application or interface.

## Using the Netlink Mini App (Legacy)

For users accessing NET through the legacy Netlink Mini App:

- Open the Mini App using a desktop, laptop, or mobile browser
- Ensure a compatible Web3 wallet is installed or accessible
- Click **Connect Wallet** to view balances associated with the connected address

The Mini App displays NET, POL (used for network transaction fees), and USDC balances on Polygon. As this application is being phased out in favor of Netlink Pay, some features may not receive further updates.

## Looking Ahead: Netlink Pay

Netlink Pay, the built-in wallet inside the core Netlink app, is designed to remove this manual setup entirely. Once available, wallet creation happens automatically behind a familiar Google login — no seed phrase, no separate wallet extension, and no manual network configuration required.

## Network Requirement

Regardless of the application used, interactions with NET require a wallet connected to the **Polygon PoS network**.

## Feature Availability and Updates

As Netlink Pay becomes available, guides and explanations for its features will be documented and updated continuously within this documentation to ensure clarity and transparency.
