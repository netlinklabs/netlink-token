This section outlines how Netlink Token (NET) is currently accessible within the ecosystem, and how that access is evolving as the Netlink platform matures.

## Netlink Pay (Primary Path Forward)

Netlink Pay is the built-in Web3 wallet inside the core Netlink app (netlink.bio). It is designed to make wallet creation and NET interaction invisible and frictionless — created behind a familiar Google login, with no seed phrase required to get started.

Netlink Pay is under active development and is intended to become the primary way users interact with NET going forward, including fee reduction, rewards, and ecosystem access as described in the Utility section.

## Netlink Mini App (Legacy)

The Netlink Mini App is an earlier, standalone web application originally built to introduce users to NET and provide basic wallet interaction using WalletConnect-compatible wallets (such as MetaMask or Trust Wallet).

As Netlink Pay matures and becomes the primary in-app wallet experience, the Mini App is expected to be phased out. Regardless of the Mini App's future availability, NET remains a standard ERC-20 token on Polygon — balances held in self-custody wallets are entirely independent of any single interface and remain safely accessible at all times.

## What Users Can Do Today

At this stage, users can:

- View NET, POL, and USDC balances via self-custody wallets
- Connect supported Web3 wallets to interact with NET on Polygon
- Prepare for participation in Netlink Pay as it becomes available

## Design Philosophy

Netlink's applications are built with a **simplicity-first** approach, prioritizing low friction and clarity over feature complexity during this stage of development.

## Path Forward

As Netlink Pay becomes available inside the core Netlink app, it will become the primary and recommended way to interact with NET. Any significant updates, transitions, or new applications will be documented transparently as they become available.
