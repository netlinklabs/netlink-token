Netlink is made up of three connected components that work together as a single ecosystem.

## Netlink

The core product. Users create a bio link, CV, or landing page to represent themselves online — a single link that consolidates identity, content, and offerings into one professional presence.

## Netlink Pay

The built-in Web3 wallet inside Netlink. A non-custodial wallet (Sequence WaaS on Polygon), created invisibly behind a familiar login (Google account), with no seed phrase required to get started. Netlink Pay enables direct, low-friction payments within the Netlink app.

## NET Token

The utility token connecting both. NET lives on Polygon and is designed to support activity across the Netlink ecosystem — including fees, rewards, and access within Netlink Pay.

## How They Work Together

These three components are designed to function as a unified experience rather than separate products. A user builds their identity through Netlink, transacts through Netlink Pay, and NET powers the utility layer connecting both — without requiring any prior crypto experience.

For more detail on NET's role within this ecosystem, see the **Utility** section of this documentation.
